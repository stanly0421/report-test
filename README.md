# 音樂播放器 (Music Player)

這是一個基於 Qt 的音樂播放器應用程式，支援本地音樂檔案播放和字幕同步顯示。

## 功能特點

- 播放本地音樂檔案（支援 mp3, wav, flac, m4a, ogg, aac 等格式）
- 字幕同步顯示（支援 SRT 格式字幕檔案）
- 播放清單管理
- 隨機播放和循環播放模式
- 音量控制和靜音功能
- 播放進度控制

## 字幕同步功能

應用程式使用 QMediaPlayer 搭配 QTimer 來實現音樂時間軸與字幕的同步顯示：

1. **解析 SRT 字幕檔案**：將字幕檔案解析為結構化資料，包含開始時間、結束時間和字幕文字
2. **定時器監聽播放位置**：使用 100ms 間隔的 QTimer 持續監聽當前播放位置
3. **動態高亮顯示**：根據當前播放位置自動高亮正在顯示的字幕
4. **可點擊跳轉**：點擊字幕時間戳可以跳轉到指定播放位置

## 建置需求

- Qt 5.x 或 Qt 6.x
- CMake 3.16 或更高版本
- C++17 支援的編譯器

## 建置方式

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## 使用方式

1. 點擊「載入音樂檔案」按鈕選擇要播放的音樂檔案
2. （可選）點擊「載入字幕檔案」按鈕載入對應的 .srt 字幕檔案
3. 字幕會隨著音樂播放自動同步高亮顯示
4. 點擊字幕中的時間戳可以跳轉到該時間點

## 程式架構

- `main.cpp` - 程式進入點
- `widget.h` - 主視窗類別定義
- `widget.cpp` - 主視窗實作
- `widget.ui` - Qt Designer UI 定義
- `CMakeLists.txt` - CMake 建置設定

## 字幕同步實作細節

字幕同步功能在 `widget.cpp` 中實作：

- `loadSrt()` - 解析 SRT 字幕檔案，建立字幕條目清單
- `onSubtitleSyncTimer()` - 計時器回呼函式，根據播放位置更新字幕高亮
- `subtitleSyncTimer` - 100ms 間隔的計時器，用於監聽播放位置變化
- `subtitleEntries` - 儲存解析後的字幕條目（開始時間、結束時間、文字）
- `currentSubtitleIndex` - 追蹤當前正在顯示的字幕索引
